# Favicon Preview

Private QA note for the Evaready Electrical favicon/app icon update.

## Source Asset

The icon design was derived from the existing Evaready Electrical logo direction in `public/images/evareadyelectrical-logo.png`, specifically the electric-blue lightning mark and dark navy brand palette.

The full horizontal logo was intentionally not used as the favicon because it becomes unreadable at browser-tab sizes.

## Preview

Local preview image: `docs/favicon-preview.png`

## Size Notes

- 16x16: readable as a compact electric lightning mark.
- 32x32: clear on light and dark browser UI.
- 48x48: clean and recognisable.
- 180x180: suitable for Apple home-screen icon use.

## Result

The favicon is square, high-contrast and brand-aligned. It does not squeeze the full horizontal Evaready wordmark into a tiny square.
